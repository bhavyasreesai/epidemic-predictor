# 🦠 AI Epidemic Predictor & Risk Dashboard

## 📌 Problem
Predicting disease spread is critical for healthcare planning and prevention.

## 💡 Solution
This project uses machine learning to predict future COVID-19 cases and classify risk levels.

## 🚀 Features
- Country-wise case prediction
- Graph visualization (Actual vs Predicted)
- Risk level detection (Low, Medium, High)
- 7-day future forecast

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
